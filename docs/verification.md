# newthing 자동화 프로젝트 검증 기록

검증일: **2026-10-22**. 인스타 카드뉴스 단일 편집 화면과 통합 설정창을 Node.js 24와 Chromium에서 확인했습니다.

## 자동 검증

**46개 테스트 통과:** 기사 추출·생성 API 19개, Cloudflare 핸들러 2개, 연결·전송·저장소 12개, Figma 파서·레이어 생성 10개, 브라우저 저장 데이터 이전 3개.

- 생성 요청은 카드뉴스용 필드 8개만 요구합니다. 응답도 해당 필드만 반환합니다.
- 카드 디자인 3종 모두 동일한 생성·편집 계약을 사용합니다.
- Figma는 1080×1350 카드 5장만 허용하며 잘못된 디자인·개수·크기를 거절합니다.
- 이전 브라우저 저장 작업·개인 키·연결 정보의 이전과 저장 공간 부족 처리를 확인했습니다.
- `npm run build`, `npm run validate`, `npm run build:cloudflare`, `npm run build:vercel`, `git diff --check` 통과.

```sh
node --test --test-reporter=spec --test-isolation=none tests/*.test.mjs
npm run build
npm run validate
npm run build:cloudflare
npm run build:vercel
```

## 브라우저 검증

**27개 브라우저 검사 통과.** 별도로 데스크톱 1440px·모바일 390px의 화면 배치와 설정창을 확인했습니다.

| 범위 | 확인 내용 |
| --- | --- |
| 초기 화면 | 디자인 메뉴·도구 연결 패널 제거, 콘텐츠가 없을 때 편집기를 숨김 |
| 편집 | 직접 작성·샘플·생성 지원, 선택한 한 장만 편집, 키보드로 카드 순환 |
| 즉시 반영 | 제목·본문·마무리·해시태그 수정과 미리보기·썸네일 동시 갱신 |
| 사진 | 이미지 변경, 새 샘플을 불러올 때 정렬 상태 초기화 |
| 추가 옵션 | 더 보기 안에서 디자인·배경 변경, 기존 렌더러 유지 |
| 통합 설정 | GPT API 키와 Figma 연결 폼이 같은 설정창에 표시 |
| 키 관리 | 브라우저 저장 해제 시 현재 탭에만 적용, 설정창을 닫으면 입력칸 비움 |
| 생성 | 모의 모델 응답 후 첫 카드 선택, 생성·직접 작성 버튼 복원 |
| 다운로드 | 개별 PNG·플러그인 ZIP, 숨겨진 편집기의 카드까지 포함한 5장 ZIP |
| 파일 내용 | 실제 PNG 5개의 1080×1350 크기와 caption.txt, 편집 가능한 Figma 프레임 5개 |
| 저장 | 생성 결과 자동 저장 |
| 모바일 | 페이지·설정창 가로 넘침 없음, 선택한 한 장을 세로로 편집 |

로컬 SQLite 서버에서 계정 연결 → 카드 전송 → 분할 데이터의 SHA-256 검증 → 완료 응답 → 웹앱 **5장 제작 완료** 표시를 확인했습니다. 테스트 연결은 종료 후 삭제했습니다.

## 검증 범위

실제 유료 GPT 호출, Figma 데스크톱 캔버스, 원격 서비스 배포는 이번 검증에 포함하지 않았습니다. 생성 흐름은 모의 모델 응답을 사용했고, Figma 레이어 삽입은 모의 호스트로 확인했습니다. Cloudflare의 공통 핸들러와 빌드를 검증했으며 원격 D1과 실제 계정 설정은 별도 확인이 필요합니다.
