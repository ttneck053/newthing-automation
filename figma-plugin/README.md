# 뉴띵 카드뉴스 자동화 — Figma 플러그인

웹앱에서 생성한 결과를 Figma Design의 **편집 가능한 프레임·텍스트·사진·도형**으로 제작하는 일반 플러그인입니다. MCP와 Figma 개인 API 토큰을 사용하지 않습니다. 기존 웹앱 PNG·ZIP 출력은 그대로 유지되며 결과 파일을 직접 옮길 필요가 없습니다.

## 설치·계정 연결

1. 실행 중인 웹앱의 **설정 → Figma → 플러그인 설치 및 전송 설정 → 플러그인 다운로드**를 누르고 ZIP을 풉니다. 다운로드한 웹앱 주소가 플러그인에 자동으로 설정됩니다.
2. Figma 데스크톱 앱에서 Design 파일을 엽니다.
3. **Plugins → Development → Import plugin from manifest…**에서 `manifest.json`을 선택합니다. `code.js`, `ui.html`을 같은 폴더에 유지하세요.
4. **뉴띵 카드뉴스 자동화**를 실행합니다. 현재 Figma 로그인 계정과 10자리 연결 코드가 표시됩니다.
5. 웹앱의 **설정 → Figma**에 코드를 입력하고 **연결**을 누릅니다. 코드는 5분 동안 유효합니다.

설치에 Node.js나 npm은 필요하지 않습니다. Community에 게시된 플러그인은 아니므로 설치 또는 업데이트 시 개발 플러그인 등록이 필요합니다. 게시할 때는 Figma에서 발급한 플러그인 ID와 배포 스튜디오 주소로 설정해야 합니다.

업데이트할 때는 웹앱에서 새 플러그인 ZIP을 다운로드해 다시 등록하세요. 기존 계정 연결을 해제한 뒤 새 플러그인의 코드로 연결합니다.

저장소의 `figma-plugin` 폴더는 `http://localhost:4177`에 연결합니다. 다른 포트·배포 주소에서는 해당 웹앱에서 ZIP을 다운로드하세요.

## 평소 사용

1. 웹앱에서 등록한 GPT 키로 결과를 생성하거나 **샘플 보기**을 누릅니다.
2. 문구·사진·색상을 편집합니다.
3. 받을 Figma 파일에서 플러그인을 열어 둡니다. 웹앱 연결 설정에 표시된 파일·페이지를 확인합니다.
4. 웹앱의 **더 보기 → Figma로 보내기**을 누릅니다. 대기 확인 주기에 따라 수신 시작까지 최대 약 10초가 걸릴 수 있습니다. 파일 선택이나 업로드 없이 카드가 추가되며 양쪽 화면에 완료 상태를 표시합니다.
5. `뉴띵 카드뉴스 자동화 · 기사 제목` 프레임의 텍스트·사진·도형을 편집합니다. 각 카드에는 PNG 내보내기 설정이 붙습니다.

인스타 카드뉴스는 **1080×1350 5장**입니다. 웹앱 연결 설정에서 가로·세로·한 줄 3장 배치를 선택할 수 있습니다. 기존 프레임은 유지하며 새 전송마다 묶음을 추가합니다. Figma 실행 취소로 추가한 묶음을 제거할 수 있습니다.

## 연결과 오류

- 계정 연결은 플러그인의 `currentUser`와 일회용 코드로 웹앱·플러그인을 짝짓는 방식입니다. Figma OAuth나 웹앱 로그인 기능은 아닙니다.
- 브라우저에는 발신용 자격 증명, Figma `clientStorage`에는 스튜디오·계정별 수신용 자격 증명을 보관합니다. 서버에는 토큰 해시를 보관합니다. 연결 해제는 양쪽 권한을 해제하며 미사용 연결은 30일 후 만료됩니다.
- 한 연결은 한 플러그인 창에서 받습니다. 다른 파일로 옮길 때는 이전 플러그인을 닫은 뒤 새 파일에서 열어 주세요. 연결 인계에는 약 45초가 걸릴 수 있습니다.
- 전송 중 페이지·파일이 바뀌면 잘못된 위치에 만들지 않고 오류를 표시합니다. 현재 위치를 확인한 뒤 다시 전송하세요.
- 플러그인을 제작 도중 닫으면 완료 여부를 확정할 수 없습니다. 중복 방지를 위해 자동 재제작하지 않으며 캔버스를 확인한 뒤 다시 전송하도록 안내합니다.
- 앱 주소 변경·브라우저 저장소 삭제·계정 변경 시 다시 연결해야 합니다. 플러그인의 수신 화면은 스튜디오 서버에 접속할 수 있어야 합니다.

## 운영 설정과 데이터

로컬 개발 서버는 `.data/figma-relay.sqlite`에 연결·전송 상태를 보관합니다. 서버 비용 0원 배포는 **Cloudflare Workers Free + D1 Free**를 사용하고 `FIGMA_DB` 바인딩을 연결합니다. 유료 Redis는 사용하지 않습니다. 무료 한도를 넘으면 전송이 제한되며 유료 플랜으로 자동 전환하지 않습니다. 운영 계정이 Free 플랜인지 확인해야 합니다.

전송 내용은 카드 문구·사진·제목·출처 URL이며 GPT API 키는 포함하지 않습니다. 전체 데이터 최대 48,000,000자, 조각당 200,000자로 분할합니다. 전송 조각은 10분 후 읽기가 만료되고 완료 시 삭제합니다. D1에 남은 만료 조각은 시간당 정리 작업으로 삭제합니다. 연결 계정·파일 이름과 마지막 작업 상태는 연결 만료까지 남습니다. SQLite의 만료 데이터는 다음 저장소 접근 때 정리하며 논리 삭제가 디스크 보안 삭제를 뜻하지는 않습니다.

다운로드한 manifest는 해당 스튜디오 출처에만 네트워크 접근을 허용합니다. 로컬 개발 주소는 `devAllowedDomains`로 설정합니다. 플러그인 UI는 스튜디오의 `/figma-receiver.html`을 열어 `/api/figma`를 사용하며, 플러그인 본체는 받은 데이터를 검증하고 Figma 레이어를 만듭니다.

## 폰트와 표현 범위

- Pretendard가 있으면 가장 비슷하게 표현합니다. 없으면 Pretendard Variable, Noto Sans KR, Noto Sans CJK KR, Inter 순으로 선택하고 대체 여부를 안내합니다.
- 웹의 750·850 두께는 설치된 폰트의 가장 가까운 스타일로 매핑합니다. 원본 줄바꿈·글자 크기·줄 간격은 전달하지만 Canvas와 Figma의 폰트 메트릭 차이로 배치가 달라질 수 있습니다.
- 제목·본문은 문단 단위 텍스트 레이어입니다. 큰 수정 시 명시적으로 들어간 줄바꿈도 조정하세요.
- 사진은 중복을 제거해 PNG로 전송하고 긴 변이 4096px을 넘으면 축소합니다. 사진을 읽지 못하면 오류를 표시합니다.
- 사진 크롭, 그라데이션, 제목 강조, 페이지 점, 로고는 편집 가능한 레이어입니다. 실패한 제작에서 새로 만든 노드는 제거합니다.
- Figma 수정 사항의 웹앱 역동기화는 지원하지 않습니다.
